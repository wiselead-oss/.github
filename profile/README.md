# WiseLead open source

Free, open-source tools from [WiseLead Solutions](https://github.com/wiselead-solutions). No paywall, no trial limits, no upsells.

| Project | What it does |
| --- | --- |
| **[PC Cleaner](https://github.com/wiselead-oss/pc-cleaner)** | Junk cleanup, duplicate and large-file finder, startup manager. Nothing is deleted without saying what will go. Files in a cloud drive are marked Cloud only and never deleted. |
| **[Power Helper](https://github.com/wiselead-oss/power-helper)** | Tray utility for Optimus laptops. |

## Getting involved

Open an issue before a large change, so we can agree on the shape of it first. See [CONTRIBUTING.md](https://github.com/wiselead-oss/.github/blob/main/CONTRIBUTING.md) and [SUPPORT.md](https://github.com/wiselead-oss/.github/blob/main/SUPPORT.md).

Found a vulnerability? Read [SECURITY.md](https://github.com/wiselead-oss/.github/blob/main/SECURITY.md) first, and please don't open a public issue.
